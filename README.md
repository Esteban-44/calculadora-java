# Java Calculator
Java project that includes two ways of performing basic math operations:
1. **Graphical calculator** (`Calculadora.java` + `Calculadora.form`): desktop interface built with Java Swing (calculator-style layout with numeric buttons and operators).
2. **Console operations** (`Main.java` + `Operaciones.java`): program that asks the user for two numbers via dialog boxes and prints the result of several operations to the console.
## Features
**Graphical calculator (Swing):**
- Addition, subtraction, multiplication, and division
- Decimal number entry
- Clear button (`C`)
**Console operations:**
- Addition
- Subtraction
- Multiplication
- Division
- Power (10 raised to the second number)
- Average
## Technologies
- Java
- Swing (graphical interface)
- NetBeans (the `Calculadora.form` file was generated by NetBeans' visual editor)
## Project structure

```
src/

```
## How to run it
### Option 1: With NetBeans
1. Clone this repository.
2. Open the project with NetBeans (it will automatically recognize the `.form` file).
3. Run `Calculadora.java` for the graphical version, or `Main.java` for the console version.
### Option 2: From the terminal
```bash
# Compile
javac -d bin src/operaciones/*.java
# Run the graphical calculator
java -cp bin operaciones.Calculadora
# Run the console version
java -cp bin operaciones.Main
```
